## 三、能力矩阵

- **规则库**：38 条，8 类攻击面（代码执行/持久化/窃取/外联/提示注入/供应链/混淆/凭据猎取）
- **AST 层**（tree-sitter/Python）：subprocess 危险调用链（区分 soffice vs curl|bash）+ 文件级变量跟踪
- **LLM 语义层**：RS-018/19 意图判定 + 静态命中逐条复核（malicious/suspicious/benign 三分，实际按二值应用）
- **IOC 查表层**：C2 IP/恶意域名直查——实测命中 rentry.co、setup-service.com、requestbin.com 等真实情报，**良性 0 误报**
- **基准体系**：可复现样本集（恶意 48 + 良性 323）+ 一键基准 + IOC 情报库

## 四、优势（数据支撑）

1. **检出率达标**：95.8% 超过 85% 目标线，且样本是真实 ClawHavoc 相关恶意技能（非合成样本）
2. **LLM 裁决有效**：误报率 44.0% → 26.6%（-40%），检出仅微降（-2%）
3. **IOC 查表零误报**：威胁情报直查比规则推断更确凿
4. **工程完整**：116 测试、CI 门禁、开源/闭源分层、英文 README、漏洞披露政策
5. **架构正确**：四层纵深（静态→AST→LLM→IOC，沙箱预留）对标 Semgrep 路线

## 五、短板（诚实评估）

| 短板 | 影响 | 根因 |
|---|---|---|
| **误报率 26.6% 离 15% 目标远** | 每 4 个正常技能 1 个被标记——"狼来了"风险 | "合法但功能强大"技能（anthropic-claude-api 76.5 分/22 命中）是结构性误报；正则层 44% 基数太高，LLM 只能压一部分 |
| 样本集 48 恶意偏小 | 统计意义有限，真实检出可能更低 | ClawHavoc 完整 824 样本未取得（已被清理） |
| AST 覆盖窄 | Python 字面量/文件级变量，跨函数/JS/Shell 未覆盖 | 数据流工程量大 |
| LLM 依赖外部 API | ~6s/包、成本、隐私 | 深度分析本为付费档设计 |
| 评分算法粗粒度 | 单维取最高权重，多命中不累加 | 组合攻击可能低估 |
| 未达 MVP 验证标准 | AGENTS.md 要求"100 个真实技能审计通过"，未执行 | 需要真实用户场景 |

## 六、行业位置

- **对 Snyk ToxicSkills**：Snyk 是研究报告（3984 技能扫描），我们是可运行产品——检测对象相同、交付形态不同
- **对 mcp-scan/Clawdex**：mcp-scan 是研究引擎，Clawdex 是 IOC 查表——我们同时具备规则+AST+LLM+IOC 四层
- **结论**：作为 **v0.1 开源产品，架构和检出达标，误报未达行业优秀线**——不是"全球前列"，但是该赛道少数可运行、可复现、开源的完整引擎

## 七、下一步建议（按优先级）

1. **误报率攻坚**：评分算法改进（多命中累加/降权组合）+ AST 跨函数数据流
2. **样本扩充**：ClawHavoc 824 完整集 + 更多良性（拉取脚本已就绪）
3. **IOC 数据自动化更新**（威胁情报 feed）
4. 真实用户验证（100 技能审计）
5. 规则包分发（变现闭环）
